# Quick Reference Sheet

*This is a one-page summary that players can use during a game.*

## Active-Day Procedure
1. Draft and submit a clear order.
2. Wait for game-master acknowledgment; revise if returned.
3. Start the stated timer, report observations, and update the order log.
4. At 22:00, pause timers and record remaining time; resume at 08:00.

## Common Actions & Their Effects
| Action | Active time |
|--------|-------------|
| Move one road/open sector | 30 min |
| Move one difficult sector | 45–60 min |
| Change formation or facing | 15 min |
| Establish a temporary position | 30 min |
| Observe one adjacent sector | 15 min |

## Contact Quick Reference
- Stop the routine timer when enemy contact, a blocked route, or a contested objective occurs.
- The game master adjudicates contested movement, combat, and capture.
- Reports use **confirmed**, **reported**, or **suspected**.

## Terrain Modifiers
| Condition | Effect |
|-----------|--------|
| Poor visibility | Add 15 min; reduce confirmation |
| Heavy rain | Add 15 min to movement/preparation |
| Night (22:00–08:00) | Freeze; no action resolves |
