# Documentation

**First-time commander? [Learn to play](learn/index.md)** is the finite
three-page public reading route. This page is a catalog, not a reading assignment.
Repository governing documents are authoritative; learning summaries and live
aids add no rules. Prototype coverage is not human-playtest validation.

| You need | Go to |
|---|---|
| Learn the first test | [Player learning route](learn/index.md) |
| Prepare or run a session | [GM route](gm/index.md) |
| Observe a playtest | [Observer guide](templates/observer-guide.md) |
| Look up a rule during play | [Quick reference](reference/quick-reference.md), [glossary](reference/glossary.md), [governing prototype catalog](reference/prototype/index.md) |
| Blank forms | [Commander sheets](templates/commander-role-sheets.md), [briefing](templates/scenario-briefing.md), [operational records](templates/operational-records.md), [playtest report](templates/playtest-report.md) |
| Understand the broader game | [Game concept](project/game-concept.md), [roadmap](project/roadmap.md) |
| Check recorded decisions | [Rule-owner decisions](decisions/rule-owner-decisions.md), [design notes](decisions/design-notes.md) |
| Revisit evidence or optional rehearsal | [AI dry run](history/2026-09-08-brackenford-ai-rules-operations-dry-run.md), [situation-band evidence](history/2026-09-10-situation-band-rehearsal-evidence.md), [fictional example](history/examples/filled-fictional-example-packet.md), [AI rehearsal](history/rehearsals/phase-4-ai-rules-operations-playtest.md), [seven-day solo rehearsal](history/rehearsals/solo-gm-seven-day-rehearsal.md) |
| Contribute safely | [Contributing](../CONTRIBUTING.md), [security](../SECURITY.md), [conduct](../CODE_OF_CONDUCT.md), [license](../LICENSE.md) |

History and optional rehearsals are not current readiness evidence or
first-test prerequisites. Snapshot/release preparation is
[optional administration](project/snapshot-and-release-preparation.md), not
permission to publish a release. Live Wiki navigation is a convenience;
the repository remains the source of authority.
