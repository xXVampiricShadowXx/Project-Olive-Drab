# Code of Conduct

## Our standards

Project Olive Drab contributors are expected to:

- Be respectful and assume good faith.
- Critique ideas, rules, and documents rather than people.
- Welcome questions and acknowledge different play and accessibility needs.
- Discuss real-world conflict thoughtfully and avoid hateful or celebratory
  language about violence.
- Protect private information shared during playtests or design discussions.

Unacceptable behavior includes harassment, discrimination, threats, personal
attacks, doxxing, sexualized harassment, and publishing private information
without permission.

## Scope

This code applies to repository issues, pull requests, discussions, reviews,
playtest materials, and other project spaces when someone is representing the
project.

## Enforcement

Report conduct concerns privately to the repository maintainers through the
security contact in [SECURITY.md](SECURITY.md). Include the relevant links,
dates, and context, but do not redistribute private information. Maintainers
will review reports, protect the reporter's privacy where possible, and take
action proportionate to the situation, including removing content or limiting
participation.

This code of conduct is adapted from the Contributor Covenant principles.
