# Security Policy

## Scope

Project Olive Drab is currently a documentation-first game-design repository.
Security reports may still concern exposed credentials, unsafe automation,
malicious links or workflow changes, or private information in playtest
materials.

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.
Instead, use GitHub's private **Report a vulnerability** feature for this
repository, if available. If that feature is unavailable, contact a repository
maintainer privately through the GitHub profile associated with the repository
and include:

- A concise description of the issue and its impact.
- The affected file, workflow, commit, or URL.
- Reproduction steps or a minimal proof of concept.
- Any suggested mitigation.

Do not include passwords, tokens, personal data, or private playtest details
unless they are necessary to reproduce the issue.

## Response

Maintainers will acknowledge a report when they can, investigate it privately,
and coordinate a fix or disclosure plan with the reporter. Please allow time
for verification before making the issue public.

There is no guaranteed response-time or bounty commitment for this project.
